# تحسين استيراد JSON

هذه الإضافة تحافظ على المراجعة الطبية الأصلية ولا تنشر استيراد JSON تلقائيًا. تعديل الأسئلة المنشورة مباشرة بواسطة Superadmin يبقى متاحًا من المسار الذي أُضيف سابقًا.

## القراءة والمراجعة

- يُقرأ الملف كاملًا محليًا في عامل منفصل عن الواجهة، بما يشمل UTF-8 وUTF-16. يُنقل مخزن الملف للعامل بدل نسخه، ويُحسب توقيعه هناك.
- تظهر الأسئلة فور اكتمال القراءة، ثم يعمل فحص التكرار مع مؤشر تقدم. تعطل الفحص يحتفظ بالأسئلة ويعرض إعادة المحاولة بدل إسقاط الملف.
- تعرض البداية عدد الأسئلة الواردة التي لها مطابقات محتملة في البنك، وعدد المطابقات المعروضة، والتكرار داخل الملف والقرارات المتبقية. تشمل مطابقات البنك الأسئلة المنشورة والمساهمات المعلقة. عدد المطابقات المعروضة ليس تعدادًا شاملًا لكل النسخ في البنك؛ المقارنة تعرض مرشحين محدودين لكل سؤال.
- يستطيع المستخدم اختيار Keep both أو Delete new أو Edit new. يبقى حذف السؤال القديم متاحًا لمن كان مخوّلًا به في النظام السابق. لا يُحذف سؤال تلقائيًا بسبب الاشتباه بالتكرار.
- يعاد ربط المقارنات المحلية بعد حذف سؤال أو تعديله، ويعاد فحص تغييرات النص والخيارات والإجابة والتصنيف. تعديل اسم المصدر أو الشرح لا يكرر الفحص الطبي للتكرار.
- يمكن تغيير اسم المصدر للملف كله أو لسؤال منفرد، مع الحفاظ على الصفحة ورقم السؤال الأصلي.
- القراءة الكاملة مستقلة عن حصة الحساب؛ تطبق الحصة على الأسئلة التي يختار المستخدم حفظها، وعلى مجموع دفعات عملية الرفع في الخادم.
- الأسئلة التي ينقصها جواب صالح أو صفحة موثقة تظل في تقرير التخطي. لا يتم اختراع تلك المعلومات لإجبار الملف على القبول.

## النص والبرومبت

يُدمج الالتفاف المفرد الناتج عن PDF/OCR داخل الفقرة، مع الحفاظ على الفقرات والقوائم والجداول والنتائج المعنونة. تبقى الأرقام والجرعات والوحدات والنفي كما هي. القراءة تدعم صيغ questionText وchoices وcorrect_answer والخيارات المعنونة، وتطابق الجواب مع ترتيب الخيارات.

احتُفظ حرفيًا بالجملة الافتتاحية للبرومبت: «This guide asks you to build a JSON file that will be uploaded to an electronic question platform.» لا توجد مقدمة تبدأ بتعريف خاص ببنك Qraft في البرومبت الحالي. تحولت تعليمات الاستخراج إلى وصف للنتيجة المطلوبة، مع الحفاظ على OCR، والتصنيف، وتخصيص المحاضرات، وأربعة خيارات للبنوك، والمصدر والصفحة ورقم السؤال، والتفسير وحدود المعلومات الخارجية السابقة. أضيف وصف للفقرات المقروءة ومطابقة الجواب وتوثيق البنود التي لا يمكن قراءتها. اسم صيغة JSON بقي qraft-question-bank-v1.

## تحكم Superadmin والأداء

من صفحة مراقبة استيراد JSON يستطيع المسؤول تفعيل الاستيراد أو إيقافه للمستخدمين، وضبط حد الملف بين 0.5 و50 MB، واختيار 25 أو50 أو100 سؤال لطلب فحص التكرار. تبقى حدود الحساب والحدود الافتراضية والإيقاف الفردي والمراقبة السابقة متاحة. عمليات الضبط تتحقق من الصلاحية والتحقق الثنائي على الخادم وتُسجَّل في سجل التدقيق. إيقاف الاستيراد العام لا يمنع المسار الإداري، وملف المسؤول محكوم بحد تقني 50 MB.

الحد الافتراضي لملفات المستخدمين بقي 1.5 MB، وأصبحت دفعة الفحص الافتراضية 50 سؤالًا. حد الملف يحمي القراءة داخل المتصفح؛ الخادم يعالج طلبات محدودة الحجم والعدد ولا يعتمد على تصريح المتصفح بحجم الملف للحماية.

استعلامات البحث محصورة بالبنك وتستعمل فهرس النص الموجود. تُرسل الاستعلامات المطلوبة للدفعة معًا، ويستعمل كشف التكرار فهرسًا للعبارات والكلمات بدل إعادة مسح كل المرشحين لكل سؤال. أصبحت قائمة المقارنة القريبة تختار المرشحين المرتبطين بالسؤال بدل أول40 سؤالًا. طلب الفحص لا يكتب سجل تدقيق أو يُرسل إشعار تغيير، والرفع يستأنف دفعاته ذات المعرفات الثابتة دون تكرار؛ عند تحديد المعدل ينتظر العميل مدة Retry-After ويحاول مجددًا بشكل محدود.

تخزين الإعدادات يستخدم سجل system/importSettings الموجود؛ لا يلزم ترحيل جديد لقاعدة البيانات.

## التحقق

اختبارات المجال والعامل تشمل ألف سؤال، النص العربي وUTF-16، اختلاف صيغ الخيارات، حفظ المعنى الطبي، تغيير المصدر، واختيار المرشحين بعد أول40 وإعادة ربط التكرار المحلي. اختبارات الخادم تشمل ضبط الإعدادات وصلاحياتها والإيقاف وحد100 للفحص وحدود الاشتراك والدفعات وإعادة الرفع وخيارات التكرار.

اجتاز المشروع187 اختبارًا، مع نجاح فحص الأنواع وفحص الكود وبناء التطبيق. أعيد اختبار مسار الاستيراد بعد إضافة حماية فحص التكرار من الإيقاف الفردي؛ نجحت اختبارات ذلك المسار أيضًا.

لم يُنفذ نشر إلى بيئة حقيقية أو اختبار قبول كامل للواجهة في المتصفح ضمن هذه الإضافة. تحسين البرومبت لا يمثل قياسًا فعليًا لجودة مخرجات نموذج خارجي؛ تعرض الواجهة الناتج للمراجعة والتحقق من المصدر.
