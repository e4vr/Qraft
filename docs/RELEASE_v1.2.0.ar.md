# إصدار Qraft v1.2.0

أذن المستخدم بنشر جميع التعديلات واعتماد النسخة الأخيرة بتاريخ 1 أكتوبر 2026. يشمل هذا الإصدار جميع تغييرات v1.1.0 ويضيف:

- إعلانًا منبثقًا يدعم الكتابة والصور، مع المعاينة والتفعيل والإيقاف من تبويب **Announcement & Telegram** في Superadmin.
- ظهور كل إعلان جديد مرة واحدة لكل حساب. تُسجّل المشاهدة عند ظهور النافذة، وتبقى مفتوحة حتى يغلقها المستخدم. تُحفظ المشاهدة في الحساب بين الأجهزة، مع حفظ محلي احتياطي للاتصال المتقطع. الزائر يعتمد على حفظ المتصفح.
- حماية مسودات الإعلان وصورها؛ صور الإعلان المحلي المنشور فقط متاحة للزوار، وإيقاف الإعلان يمنع الوصول العام إليها.
- زر أفقي بشعار تيليجرام أعلى الإعدادات، مرتبط افتراضيًا بـ `https://t.me/QraftQBanks`، مع إمكانية تعديل الرابط أو إخفاء الزر من Superadmin.
- إصدار ذاكرة PWA جديد `v4.7.2` لتحديث التطبيقات المثبتة وإزالة ذاكرة النسخة السابقة.
- تحديث متوافق للمكتبة التابعة `hono` إلى `4.13.12` لمعالجة التنبيه الأمني المكتشف أثناء فحوص الإصدار، دون تغيير بقية المكتبات.

لا يضيف الإصدار ترحيلًا لقاعدة البيانات؛ يستخدم سجلات الإعدادات وتفضيلات المستخدم الحالية. آخر ترحيل قائم هو `0028_full_access_plans.sql`.

مسار النشر هو `scripts/deploy-production.mjs` من التزام Git نظيف، مع تضمين SHA وإصدار التطبيق وذاكرة PWA والمخطط في ترويسات استجابة الموقع. يعتمد الإصدار على الفرع الرئيسي ووسم `v1.2.0`، ويُعتمد بوصفه Latest في GitHub بعد النشر والتحقق.

نقطة العودة قبل الإصدار: تطبيق Cloudflare `247e2b3d-d337-42b5-b36d-ec1496ba6ff6`، وخدمة التحديث المباشر `f678d090-8bbe-4b79-8858-303890cbc09a`. نتائج الاختبارات والنشر وفحص هوية صفحات الإنتاج تحفظ محليًا في `outputs/` وتُلخّص في إصدار GitHub.

تفاصيل التشغيل والصلاحيات موثقة في [الإعلان وقناة تيليجرام](ANNOUNCEMENTS_TELEGRAM_2026-10-01.ar.md).
