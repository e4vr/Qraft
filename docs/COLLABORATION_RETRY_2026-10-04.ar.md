# إعادة محاولة حذف المساهمات المتعثر

يقسم العميل حذف المساهمات المستقلة داخل البنك إلى دفعات متتابعة، بحد أقصى 500 عملية و1,700,000 بايت لكل طلب. تبقى مجموعات نشر الأسئلة وتغيير التصنيف المترابطة ضمن حدودها الأصلية ولا تُقسم تلقائيًا.

بعد تأكيد الخادم نجاح الدفعة، تُحدّث قائمة الانتظار والمسودات المرفوضة ضمن معاملة IndexedDB واحدة. إذا تعثرت الدفعة التالية، تُعاد محاولة المتبقي فقط. تُحفظ تعديلات المستخدم الأحدث أثناء الطلب ولا تُستبدل بلقطة قديمة.

زر **Sync now** يحفظ التغييرات الحالية ثم يعيد محاولة عمليات حذف المساهمات المسجلة ضمن المسودات المرفوضة على الجهاز والحساب نفسه. يقرأ الحالة الحالية أولًا، ويتجاوز العناصر التي تغيرت لتبقى للمراجعة، ويرسل بصمة القيمة الأصلية لمنع حذف عنصر تغير بعد القراءة. العناصر غير الظاهرة تحتاج تأكيد الخادم أيضًا؛ عدم ظهورها قد ينتج عن فقدان الصلاحيات.

لا تُرسل لقطة المسودة التاريخية كاملةً، ولا تُعاد تلقائيًا عمليات النشر أو التصنيف المترابطة أو تغييرات البنوك والحسابات. تبقى التغييرات غير القابلة لإعادة المحاولة متاحة للتنزيل والمراجعة. ملف JSON المنزّل نسخة حفظ؛ هذه الميزة تستخدم المسودات المحفوظة في المتصفح ولا تضيف استيرادًا للملف.

لا يتغير حد الخادم أو التحقق من الصلاحيات، ولا يحتاج التعديل ترحيل قاعدة بيانات. تشمل الاختبارات حالة 614 عملية (500 ثم 114)، والانقطاع بعد الدفعة الأولى، والمسودات القديمة، وتعارض القيم، والصلاحيات، وتغير الحساب، والضغط المتزامن، وحفظ التعديلات الأحدث، وحجم UTF-8، وقبول دفعات الحذف عبر API مع الحفاظ على الأسئلة المنشورة.
