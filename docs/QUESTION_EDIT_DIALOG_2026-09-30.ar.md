# نافذة تعديل السؤال وطلب التعديل

تقسم النافذة إلى نوع التعديل، ومحتوى السؤال وخياراته، والشرح، والمصدر، وسبب التعديل. في الشاشات الكبيرة يظهر المصدر والسبب بجانب محتوى السؤال، وعلى الجوال تتتابع الأقسام رأسيًا.

تستخدم الحقول والأقسام حدودًا وخلفيات أوضح في الوضع الداكن والفاتح. اختيار الإجابة الصحيحة يكون بجانب الخيار مباشرة مع تمييزه بالأخضر. يبقى عنوان النافذة وأزرار الإلغاء والحفظ ظاهرين أثناء تمرير المحتوى.

اسم ملف المصدر مطلوب ورقم الصفحة اختياري. تبقى قواعد التحقق والحفظ والصلاحيات كما هي: طلب المستخدم يخضع للمراجعة، وتعديل Superadmin يطبق مباشرة مع توضيح أثر المقترحات المعلقة.

تم فحص العرض بعرض 1792 و390 بكسل، وظهور أزرار الحفظ دون تجاوز الشاشة، وإضافة الخيارات وحذفها مع بقاء الإجابة الصحيحة مرتبطة بالخيار، وتفعيل الإرسال بعد استكمال الحقول المطلوبة. فحص العرض لم يرسل طلبات تعديل ولم يغير الأسئلة.

التنفيذ في `components/question-edit-dialog.tsx`، مع الإبقاء على مسار الحفظ الأصلي في `components/medguard-app.tsx`.
