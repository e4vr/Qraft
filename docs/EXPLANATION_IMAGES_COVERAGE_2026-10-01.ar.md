# تغطية صور شرح الحل

أضيف حقل اختياري `explanationImages` إلى السؤال ومساهمة السؤال وسؤال الاختبار الجاهز. هذا الحقل مستقل عن `images` الخاصة بنص السؤال، وعن `sharedNotes.images` الخاصة بالملاحظات العامة. تعرض شاشة الحل صور السؤال المعتمدة وصور الملاحظات العامة، مع تجنب تكرار الرابط نفسه.

## المداخل التي تمت تغطيتها

| المدخل | التنفيذ |
| --- | --- |
| إنشاء السؤال من صفحة المساهمات، سواء بصفة مالك أو مساهم | محرر صور الشرح داخل `QuestionManager` |
| تعديل مساهمة معلقة أو إعادة إرسال مساهمة مرفوضة | تحميل صور المسودة الحالية وإعادة حفظها في المحرر نفسه |
| إضافة سؤال يدويًا من إدارة البنك | محرر صور مستقل أسفل شرح الحل |
| تعديل سؤال من إدارة البنك | تحميل الصور القديمة، تعديل الأوصاف والإضافة والإزالة |
| تعديل السؤال من شاشة الحل أو إرسال اقتراح تعديل | `QuestionEditDialog` مع صور الشرح؛ الحفظ الإداري المباشر والمسار الخاضع للمراجعة |
| استيراد JSON من صفحة المساهمات أو إدارة البنك | قبول `explanationImages` في الملف وإمكانية رفع الصور في مراجعة كل سؤال قبل الإرسال |
| إضافة سؤال أو تعديله أو استيراده داخل الاختبار الجاهز | المحرر نفسه، مع صلاحيات رفع صور الاختبار القائمة |
| Shared notes / الملاحظات العامة | اختيار الصور ولصقها وسحبها، مع الوصف والإزالة والتكبير وحفظها في سجل الملاحظات |
| مراجعة المساهمات ومقارنة الأسئلة المكررة | عرض صور الشرح للمحتوى الحالي والمقترح |
| عرض الشرح على الكمبيوتر والهاتف، وعرض حل الاختبار الجاهز | الصور والأوصاف مع إمكانية التكبير |

## الحفظ والتوافق

- جميع النماذج تستخدم بيانات الصور نفسها: `id`, `url`, `name`, `caption`.
- قبول المساهمة ينقل الصور إلى السؤال المنشور. تحديث السؤال المباشر يراجع صحة المرفقات قبل الكتابة.
- إرسال عميل قديم لا يتضمن الحقل يحافظ على صور السؤال الموجودة عند التعديل والاعتماد. إرسال مصفوفة فارغة يعني إزالة صور الشرح صراحةً.
- ملفات الاستيراد القديمة تستمر بالعمل. الملفات التي تتضمن المرفقات تحافظ عليها، والمرفقات غير الصالحة تظهر ضمن الأسئلة المستبعدة مع السبب.
- البيانات محفوظة ضمن JSON الحالي؛ لا يحتاج التغيير إلى ترحيل قاعدة بيانات.

## ضوابط الرفع والعرض

المحرر يقبل JPEG وPNG وWebP وGIF، خمس صور لكل دفعة و10 MiB لكل صورة. الحد الإجمالي عشر صور لشرح سؤال البنك وخمس صور لشرح سؤال الاختبار الجاهز. يدعم اختيار الملفات ولصقها وسحبها، ويحتفظ بالملفات التي نجح رفعها إذا فشل ملف آخر، مع رسالة توضح الفشل.

يتوقف الحفظ والإغلاق والتنقل بين أسئلة المحرر أثناء الرفع. يستخدم المحرر آخر بيانات المسودة عند اكتمال الرفع حتى لا تضيع تعديلات النص المتزامنة. لا يضيف رفع انتهى بعد مغادرة المحرر الصور إلى سؤال آخر.

المرفقات العامة تستخدم مسار `media/shared-notes` مع صلاحية الوصول للبنك وصلاحية رفع الصور. مرفقات الاختبار الجاهز تستخدم مساره القائم. تُحذف صور الشرح من استجابة فتح الاختبار بوضع الامتحان حتى التسليم. صور الاختبار الخاص تحمل رمز المحاولة عند عرضها للمشارك، بما في ذلك استجابة الحل واستعادة نتيجة تسليم سابق.

## التحقق

تشمل الاختبارات حفظ الصور وتعديلها وإزالتها، التوافق مع العملاء والملفات القديمة، إرسال السؤال واعتماده، رفض الروابط غير الآمنة، حدود المرفقات، عرض الأوصاف وأزرار التحكم، خصوصية البنك، صلاحيات الحساب المجاني، وإخفاء صور الشرح أثناء الامتحان واستعادتها بعد التسليم. أُجري أيضًا فحص الأنواع والجودة وبناء التطبيق. هذه تغطية للكود واختبارات آلية؛ لم تُجرَ جولة تفاعلية كاملة في المتصفح، ولم يُنشر التغيير على الإنتاج.

النتيجة النهائية: نجحت جميع الاختبارات الـ259، وفحصا الأنواع والجودة وبناء التطبيق. أُعيدت اختبارات محرر الصور الثمانية بعد ضبط دورة انتهاء الرفع وتغيير المسودة ونجحت جميعها.
