# Import — السلوك والإدارة

تم تنفيذ طلب المستخدم الأصلي، دون إضافة ملخص مراجعة أو تصنيفات مرئية متعددة للتكرار.

- الاسم المرئي للميزة: Import.
- اسم الملف وبصمته بيانات تشغيلية فقط؛ لا تمنع إعادة استيراده. معرّف عملية الرفع يمنع تكرار الحفظ عند إعادة المحاولة.
- تتم مراجعة الأسئلة قبل الحفظ. السؤال المشتبه بتكراره يحمل وسم duplication، مع Save as duplication وView the duplication.
- المقارنة تعرض السؤالين وخياراتهما وإجابتهما ومصدرهما وشرحهما. القرارات: الاحتفاظ بالاثنين، حذف الجديد، حذف القديم وفق الصلاحيات، أو تعديل الجديد وإعادة فحصه.
- حفظ النسختين لا يتجاوز مراجعة المحتوى الطبي أو صلاحيات نشر الأسئلة العامة. يحتفظ الخادم بقرار الاحتفاظ فقط عندما تطابق بصمات النسخ المعروضة النسخ الحالية.
- لا توجد عقوبة تلقائية للتكرار أو تخفيض جديد للثقة. ترحيل 0026 يلغي التعليقات الآلية السابقة ويزيل سجل عدّاد العقوبات. درجات الثقة التاريخية لا تتغير؛ تبقى سجلات المراجعة والتدقيق.
- البرومبت باللغة الإنجليزية، ويشرح بناء ملف JSON للمنصة وفق المصدر والتخصيص الحالي. المحاضرات تعتمد على المصدر وحده. البنوك تستخدم النص القابل للنسخ أو OCR، وتصحح الإملاء وفق السياق، وتكمل أربعة خيارات منطقية عند الحاجة، وتضيف رقم السؤال والصفحة وشرح الحل. المعرفة الخارجية مسموحة لشرح الحل فقط عند غياب الشرح من البنك.

## إدارة الحدود

داخل Superadmin → Imports → Import limits & access:

- حد عام قابل للتعديل: 1–5000 سؤال إجمالًا لكل ملف، و1–100 عملية استيراد لكل مستخدم في اليوم وفق UTC.
- يمكن تخصيص الحدين لحساب محدد. التخصيص الفردي يسبق الحد العام، ثم تأتي حدود الباقة عندما تُترك الحدود العامة فارغة.
- التعليق اليدوي للاستيراد: 1–365 يومًا، مع إمكانية إلغائه. لا يوقف بقية التطبيق.
- الاستيراد المقسّم يُحسب عملية واحدة. يفرض الخادم مجموع الأسئلة عبر جميع دفعات العملية، ويمنع تجاوز الحدود حتى عند التنفيذ المتزامن. إعادة محاولة الدفعة المحفوظة لا تضاعف الحفظ أو الحصة.
- المسار الإداري لـSuperadmin يحتفظ باستثناء حصص الاشتراك؛ الواجهة ترفع دفعات من 25 سؤالًا، والمسار الإداري يقبل حتى 250 سؤالًا في الطلب الواحد. حد الطلب العادي 150 سؤالًا. هذه حدود تنفيذ للدفعة، وليست حدودًا لحجم ملف المستخدم الكلي. لا تنتقل صلاحيات Superadmin إلى المستخدمين.
- تظل حدود حجم الطلب وحصة الأسئلة قيد المراجعة وصلاحيات الباقة نافذة. تغيير عدد الأسئلة لا يمنح صلاحية الاستيراد لباقة لا تدعمه.

## التنفيذ والتحقق

البحث في نص السؤال محصور داخل البنك، ويستعين بفهرس FTS5 داخل D1 مع نتائج محدودة قبل المقارنة. الفهرس يتحدث مع إضافة السؤال وتعديله وحذفه؛ لا توجد خدمة AI أو embeddings مدفوعة لهذا الفحص. معاينة التكرار عملية قراءة ولا تصدر إشعارات تغيير للموقع.

مراجع المنصة: [دعم FTS5](https://developers.cloudflare.com/d1/sql-api/sql-statements/)، [حدود D1](https://developers.cloudflare.com/d1/platform/limits/).

اختبارات السلوك تشمل: تكرار الاسم والمحتوى، نص مطابق بخيارات مختلفة، تغير التنسيق وترقيم السؤال، حفظ النسختين، منع الحذف دون صلاحية، رفض الحذف عندما تتغير النسخة، حد الأسئلة عبر دفعات الملف، إعادة المحاولة، التعليق اليدوي ومدته، عدم إنشاء عقوبات، وصلاحيات Superadmin.

يجب تطبيق ترحيل 0026 قبل نشر نسخة التطبيق. تم التحقق على بيانات محلية ومعزولة؛ لم يتم النشر على الموقع الفعلي.
