# إصدار Qraft v1.1.0

أذن المستخدم بنشر جميع التعديلات السابقة على GitHub وCloudflare واعتماد هذه النسخة بتاريخ 1 أكتوبر 2026. يجمع هذا الإصدار التغييرات التالية:

- إرفاق الصور بالملاحظات العامة وشرح السؤال في الإنشاء والتعديل والاستيراد والمراجعة والأسئلة الجاهزة.
- زر شروط الاسترجاع في الإعدادات، وإمكانية تعديل رابطه من Superadmin.
- الموافقة على الشروط والأحكام قبل الانتقال إلى WhatsApp لإتمام الاشتراك.
- قيم نقاط المساهمات الجديدة بعد القبول، دون منح نقاط لإضافة سؤال مستورد أو إعادة احتساب الأرصدة السابقة.
- مكافآت Full Access: أسبوع مقابل 200 نقطة، شهر مقابل 400، وثلاثة أشهر مقابل 850.
- زيادة المساحة السفلية لأزرار الاختبار، وزر تعديل السؤال باللون البرتقالي، وإزالة مربع الإرشادات من قسم الشرح.
- تحديثات أمنية متوافقة للمكتبات التابعة `brace-expansion` و`fast-uri` و`ip-address`، وتثبيت `undici` المستخدم تحت `shadcn` على `7.30.0` دون تغيير نسخة أدوات Cloudflare.

نسخة التطبيق: `1.1.0`. نسخة ذاكرة PWA: `v4.7.1` لتحديث التطبيقات المثبتة وإزالة ذاكرة الواجهة السابقة. آخر ترحيل قائم: `0028_full_access_plans.sql`. فحص قاعدة الإنتاج قبل النشر أكد عدم وجود ترحيلات معلقة، ولم تُضف ترحيلات جديدة لهذا الإصدار.

مسار النشر هو `scripts/deploy-production.mjs` من التزام Git نظيف، مع تضمين SHA والنسخة وتاريخ البناء في بيانات الإصدار. الفرع الرئيسي ووسم `v1.1.0` يشيران إلى الالتزام المعتمد، ويمكن مطابقة SHA مع الترويسة `x-qraft-build` في التطبيق المنشور.

إصدارات Cloudflare السابقة المحفوظة قبل النشر:

- التطبيق: `75c1b2fc-cfe2-485f-bd45-914e6c21041a`.
- خدمة التحديث المباشر: `f678d090-8bbe-4b79-8858-303890cbc09a`.

التحقق قبل النشر: نجحت الاختبارات الكاملة (266 اختبارًا)، واختبارات قاعدة البيانات التجريبية (12 اختبارًا)، وفحص TypeScript وlint، وبناء الإنتاج والتجربة ومحاكاة نشر العاملين عبر Cloudflare dry-run. فحص `npm audit --omit=dev --audit-level=high` لم يُظهر ثغرات معروفة في حزم الإنتاج. أدلة التشغيل تحفظ محليًا في `outputs/`، والتحقق من صفحات الإنتاج وهوية البناء ومعرّفات Cloudflare يوثق أيضًا في إصدار GitHub بعد النشر.
