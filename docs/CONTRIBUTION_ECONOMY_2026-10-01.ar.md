# تحديث نقاط المساهمات والمكافآت

تطبق القيم التالية عند القبول النهائي للمساهمة. لا تعيد هذه التعديلات احتساب الأرصدة السابقة أو مجموع نقاط المساهمة التاريخي.

| المساهمة | النقاط |
| --- | ---: |
| سؤال جديد يدويًا | 1 |
| سؤال جديد مستورد | 0 |
| تصحيح إملائي أو تنسيق | 1 |
| تحسين المصدر | 1 |
| بلاغ صحيح مرتبط بسؤال | 2 |
| تحسين الشرح | 4 |
| تعديل نص السؤال أو الخيارات | 8 |
| تصحيح الإجابة الصحيحة | 10 |

يستمر اعتماد الأسئلة المستوردة ونشرها، دون إضافة حركة نقاط بقيمة صفر. يحتفظ الاقتراح بطريقة إدخاله ومعرّف دفعة الاستيراد عند تعديله من صاحبه. يمكن لتحسين لاحق لسؤال مستورد أن يكسب نقاطًا بحسب نوع التحسين.

تمنح المساهمة الواحدة مكافأة واحدة بحسب أولوية أنواع التعديل الموجودة في الاقتراح. تبقى صلاحيات المراجعة واشتراطات المراجعين المستقلين كما كانت. البلاغ الصحيح يمنح نقطتين عند إغلاق البلاغ المرتبط بسؤال باعتباره محلولًا من Superadmin. إعادة الاعتماد أو إغلاق البلاغ مجددًا لا تمنح مكافأة إضافية.

| مكافأة Full Access | التكلفة |
| --- | ---: |
| أسبوع: 7 أيام | 200 نقطة |
| شهر | 400 نقطة |
| ثلاثة أشهر | 850 نقطة |

تظهر مكافأة الأسبوع في مركز المساهمات والأهداف والمحفظة. تبدأ الأيام السبعة عند تفعيل المكافأة، وليس عند شرائها بالنقاط. تستخدم حقل `duration_days` الموجود مسبقًا، ولا تحتاج إلى ترحيل جديد لقاعدة البيانات. تبقى المكافآت التي سبق شراؤها صالحة بمددها المخزنة.

تغطي الاختبارات قيم جميع أنواع المساهمة، القبول المستقل، الاستيراد دون نقاط، الحفاظ على التاريخ، تكلفة المكافآت، منع الخصم المكرر، ومدة الأسبوع وصلاحيتها بعد التفعيل.
