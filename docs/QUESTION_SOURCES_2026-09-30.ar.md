# توحيد مصادر الأسئلة وفصل رقم الصفحة

تعتمد فلترة الأسئلة في QBank → Questions على اسم المصدر، دون رقم الصفحة أو رقم السؤال الأصلي. تعرض قائمة المصادر عدد الأسئلة لكل مصدر، ويمكن جمع فلتر المصدر مع البحث والتخصص والموضوع.

## صيغة JSON

- `sourceFile`: اسم الملف الأصلي أو المحاضرة، مطلوب. يمكن تعريفه مرة واحدة أعلى الملف ليُستخدم لجميع الأسئلة، أو داخل السؤال لتغيير مصدره.
- `sourcePage`: رقم صفحة أو شريحة مستقل، اختياري. يُحذف الحقل عندما تكون الصفحة غير معروفة؛ لا تُستخدم قيمة صفر. عند إضافته يجب أن يكون عددًا صحيحًا بين 1 و100000.
- `originalQuestionNumber`: رقم السؤال في المادة الأصلية، اختياري ومستقل عن هوية المصدر.
- `sourceReference`: مرجع عرض يُشتق من الحقول السابقة؛ لا يحدد هوية المصدر في الفلترة.

مثال صالح للاستيراد؛ السؤال الأول بصفحة معلومة والثاني دون صفحة:

```json
{
  "format": "qraft-question-bank-v1",
  "sourceFile": "Lecture.pdf",
  "questions": [
    {
      "stem": "Example question with a known page?",
      "options": ["First option", "Second option"],
      "correctAnswer": "A",
      "specialty": "General",
      "topic": "Example",
      "explanation": "Example explanation for the first option.",
      "sourcePage": 12,
      "images": []
    },
    {
      "stem": "Example question without a known page?",
      "options": ["First option", "Second option"],
      "correctAnswer": "B",
      "specialty": "General",
      "topic": "Example",
      "explanation": "Example explanation for the second option.",
      "images": []
    }
  ],
  "skipped": []
}
```

اسم ملف JSON المرفوع لا يُستخدم بديلًا تلقائيًا للمصدر الأصلي؛ فقد يكون مجرد ملف تصدير. السؤال الذي لا يتضمن مصدرًا قابلًا للقراءة يُدرج في تقرير الأسئلة المتجاوزة، مع استمرار استيراد الأسئلة السليمة.

يحتوي AI Prompt المنسوخ من صفحة الاستيراد على مثال منسق لسؤال بصفحة وآخر دون صفحة، مع اسم مصدر مشترك. يطابق عدد الخيارات إعداد المحاضرة المختار، وتستخدم أمثلة تحويل البنوك أربعة خيارات. يمكن فتح «Preview final JSON format» لمعاينة البنية مباشرة. يطلب النص حذف الحقول الاختيارية المجهولة، وعدم توليد `sourceReference` أو معرّفات أسئلة التطبيق، وتوحيد كتابة اسم المصدر مع الحفاظ على أسماء الإصدارات الفعلية.

## البيانات الموجودة

تُقرأ الصيغ القديمة الواضحة مثل `Lecture.pdf - p.12 - Q.37` وتُفصل لأغراض العرض والفلترة. تبقى أرقام الإصدارات في أسماء الملفات والمراجع الملتبسة دون تخمين. تتجاهل هوية المصدر اختلاف حالة الأحرف والمسافات المتكررة، وتحتفظ باسم العرض. يظهر المصدر الناقص القديم باسم «Unspecified source».

تستخدم الإضافة والتعديل واقتراح التعديل ومراجعة الاستيراد حقلي المصدر والصفحة. إزالة الصفحة عند الحفظ تزيلها من المرجع أيضًا، مع الحفاظ على رقم السؤال الأصلي عند توفره.

لا يتطلب هذا التغيير ترحيل قاعدة البيانات؛ الحقول محفوظة ضمن بيانات السؤال الحالية. لا يعيد كتابة جميع السجلات القديمة، ولا يغير معرّفات الأسئلة أو تقدم الدراسة أو لقطات الاختبارات المنشورة سابقًا. تبقى صلاحيات التحرير والمراجعة والحماية الإدارية كما هي.

## التحقق

شملت الاختبارات استيراد الأسئلة دون صفحة، رفض الصفحات غير الصالحة، تجميع صفحات المصدر الواحد، قراءة المراجع القديمة، وحذف الصفحة عبر الحفظ المباشر واعتماد الاستيراد. شملت المعاينة المحلية فلترة ثلاثة أسئلة من صفحات مختلفة تحت مصدر واحد، ودمج البحث مع الفلتر، وعرض حقلي المصدر والصفحة في نموذج التعديل.
